# Netflix-Content-Analytics-Dashboard
An end to end data analytics project exploring Netflix's global content catalog, cleaned and analyzed using SQL, visualized in an interactive Tableau dashboard.

Objective

Explore Netflix's catalog to understand content trends — Movies vs. TV Shows, top countries, growth over time, ratings, and top directors — the kind of analysis a content team would use for catalog planning.

Tools Used

SQL · Tableau · Google Sheets

Dataset

Netflix Movies and TV Shows (Kaggle) — ~8,800 titles

My Role

Cleaned the raw data, wrote 15 SQL queries to answer key content questions (see netflix.sql), and built the full Tableau dashboard.

Dashboard Highlights
Type of Content (Movies vs. TV Shows)
Top 10 Countries by content volume
Content Growth by Decade
Content Added Over Time
Rating Distribution
Top Directors

Key Insights
Catalog is ~70% Movies, ~30% TV Shows
US and India lead content production
Content acquisition peaked in the 2010s
Rajiv Chilaka is the most-represented director — pointing to a large kids'/animated content share
